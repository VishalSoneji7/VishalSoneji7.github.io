// WHAT I BUILT

C++ · NETWORKING
Split-Screen Co-op

Architected a split-screen co-op system in C++ on a listen-server model, partitioning a 1920×1080 viewport into two independent 960×1080 player-controller cameras at runtime with dedicated HUD layers per player — enabling seamless local + online co-op as a core feature.

RENDERING · POST-PROCESS
Occlusion Silhouette

Built a player occlusion silhouette using a Custom Depth stencil and a hand-authored post-process material, rendering a colored outline whenever a player is hidden behind geometry. It sharpened spatial awareness — 70% of players responded positively across all 6 levels.

SKELETAL MESH
Cosmetic Skin System

Engineered a skeletal socket and bone-attachment framework, authoring 5 sockets (head, neck, torso, left/right wing) in the Skeleton Editor so every accessory animates correctly with player movement at runtime — a deployable cosmetic progression layer.

PERFORMANCE · LUMEN
Lighting Optimization

Led lighting optimization across all 6 levels in a mixed static/Lumen pipeline, auditing 100+ lights via Optimization View modes to eliminate GPU overdraw — lifting frame rate from an unstable 50fps to a consistent 90–120fps on target hardware.

GAMEPLAY
Cross-Discipline Bug Fixing

Resolved 15+ cross-discipline gameplay bugs, including a checkpoint/respawn regression that spawned players underground — fixed by replacing random sphere-offset logic with a deterministic world-space height clamp against level collision.

frustum_culling.log Prime Engine · C++

Testing Visibility with 1,000 Imrods

Starting with the course-provided Prime Engine, I built bounding-box calculations, colored debug boxes, and six camera-plane tests, including near and far boundaries. I used a scene of 1,000 Imrods and the FPS counter to compare objects in and out of view. On my gaming laptop, I observed approximately 40 to 90 FPS while recording and 90 to 260 FPS without recording. The project notes describe the hardware, comparison, and implementation limits.

physics_collision.log Prime Engine · C++

From Passing Through Obstacles to Sliding Along Them

The supplied engine let the soldier walk straight through the car. I built sphere-based character collision, box collision for the car, and floor-plane detection. The collision query finds the closest point on the box in local coordinates and checks its distance from the character in world space. The demo shows the soldier colliding and sliding along the car, then falling when it walks beyond the floor.

animation_blend.log Prime Engine · C++

Making Existing Animation Clips Blend

Prime Engine supplied animation clips, but they could not blend. I implemented full-body, partial-body, and additive blending in C++. Full-body blending combines weighted joint poses, partial-body selection splits contributions by joint range, and additive blending applies a source/reference transform difference to a target pose. Debug labels show the active animation tracks, frame positions, and weights.
